3D Globe & 2D GIS Monitoring System

แพลตฟอร์มจำลองลูกโลกสามมิติเสมือนจริง (Interactive 3D Virtual Globe) และระบบแผนที่ภูมิสารสนเทศสองมิติ (2D GIS Map) พัฒนาเพื่อแสดงผลข้อมูลภัยพิบัติและการตรวจวัดสภาพอากาศสดแบบ Real-Time จากแหล่งข้อมูลที่น่าเชื่อถือระดับสากล

Architecture & Data Feeds:
• USGS Real-time GeoJSON: แผ่นดินไหวล่าสุดพร้อมความลึกและคลื่นสั่นสะเทือน
• Globe.gl + Three.js: เอนจินเรนเดอร์ WebGL ความละเอียดสูง
• Leaflet.js & Esri Satellite: แผนที่ภาพถ่ายดาวเทียมความละเอียดสูง 4K
• Tectonic Plates Database: PB2002 ขอบแผ่นเปลือกโลกทางธรณีวิทยา
• Open-Meteo REST API: ดึงข้อมูลสภาพอากาศทั่วโลก
